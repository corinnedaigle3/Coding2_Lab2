# Coding2_Lab2

## **Custom Editor**

This lab focuses on creating a custom editor that consists of different actions for 5 cubes and 5 spheres. It also shows a warning in th inspector when the size variable is changed.

Actions:

• Selecting all the cubes or spheres.

• Clearing the selection.

• Disabling/enabling all the cubes or spheres.

• A variable for the size of the cubes or spheres.
